# 🦈 Wireshark Basics – Beginner Guide

This project explains **Wireshark** in a simple and easy-to-understand way for beginners.  
Wireshark is a powerful **network packet analyzer** used to capture and analyze network traffic 🌐📦.

The goal of this project is to help beginners understand:
- ❓ What Wireshark is
- 🎯 Why it is used
- 🔗 How network packets work
- 🛡️ How Wireshark is useful in cyber security and networking

---

## 📘 What is Wireshark?

Wireshark is a free and open-source tool that captures **live network packets** and displays detailed information such as:
- 🖥️ Source and destination IP addresses
- 📡 Protocols (DNS, TCP, UDP, HTTP, HTTPS)
- ⏱️ Packet size, timing, and data flow

It works like a **network traffic monitoring camera** 📷🌐.

---

## 🎯 Why Wireshark is Used

- 🛠️ Network troubleshooting
- 📚 Learning how the internet works
- 🚨 Detecting suspicious or malicious traffic
- 🔐 Cyber security analysis
- 📊 Protocol analysis

---

## 🔍 Example Explained

When a user opens a website (e.g., google.com 🌍):
1. 📤 A DNS request is sent to find the IP address
2. 🔁 TCP connection is established
3. 🔒 Secure data transfer happens using HTTPS

Wireshark captures and shows each of these steps as packets 📦📦.

## 🛡️ Cyber Security Use Case

Wireshark helps identify:
- ⚠️ Unusual traffic patterns
- 🔑 Brute-force attacks
- 🦠 Malware communication
- 📤 Data leaks
